TONEGRID — ICONE APPLICATION

Symbole repris des tracés du logo ToneGrid de référence, sans modification de sa géométrie.
Symbole blanc sur un carré anthracite arrondi. Extérieur transparent.

Windows : ToneGrid.ico (plusieurs résolutions incluses).
macOS : ToneGrid.icns (plusieurs résolutions incluses).
Linux : ToneGrid.svg et PNG selon les tailles requises par le thème d’icônes.
Source vectorielle : ToneGrid.svg.
PNG : 16, 20, 24, 32, 40, 48, 64, 128, 256, 512 et 1024 pixels.

Les fichiers sont prêts à être intégrés aux ressources de l’application.
La configuration de compilation dépend du framework de votre application.
