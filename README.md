# ToneGrid

ToneGrid is a desktop guitar pedalboard and NAM amplifier/cabinet application, with PLAY, JAM, LEARN and RECORD modules, local presets, guitar calibration and recording/export tools.

**Maintainer:** [L’équipe ToneGrid](https://github.com/tonegrid).  
**Project co-lead and maintainer:** Christian Berlovan ([tonegrid](https://github.com/tonegrid)).

**Website:** https://www.tonegrid.net  
**Downloads:** https://www.tonegrid.net/download/  
**Public download repository:** https://github.com/tonegrid/tonegrid-downloads

Source home: **https://github.com/tonegrid/tonegrid-source**. The owner approved this separate public source repository on 27 October 2026. The private development repository is preserved; no private Git history is part of this source snapshot.

## Platforms and source identity

Windows x64 and macOS Apple Silicon (macOS 13 or later target) have distributed builds. Linux has build support but no validated released Linux binary in this audit. macOS Intel/Universal builds are not claimed.

This public source snapshot is not a claim that its complete content equals an already distributed binary. The original C++ application sources are unchanged by publication preparation. Current ToneBank editorial changes postdate the Windows release. [releases/README.md](releases/README.md) distinguishes verified Windows corresponding sources from unresolved Mac source correspondence.
