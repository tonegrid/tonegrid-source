# Security reporting

Contact the ToneGrid maintainers through https://www.tonegrid.net or https://github.com/tonegrid. Do not put tokens, recordings, browser cookies, signing material or unredacted personal diagnostics into public issues. No security inbox or disclosure response time is promised without maintainer confirmation.

Verify download checksums against the release manifest. A valid checksum demonstrates byte identity, not code safety or signing-provider approval. Only reviewed CI builds should be signed; keep signing credentials out of source, artifacts and logs.
